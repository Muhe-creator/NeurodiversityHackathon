# 🤖 Neuroadaptive AI Classroom
### AI-Driven Autism Support System — by Team Inspire 92

This project was developed during the April 2025 Microsoft Neurodiversity Hackathon. It aims to support autistic children in classroom settings through **real-time bio-signal monitoring** and **adaptive environmental interventions**.

## 🧩 What Problem Does It Solve?

Children with autism often experience:
- Sensory overload (e.g., flickering screens, loud sounds)
- Social withdrawal and anxiety
- Emotional outbursts triggered by classroom stimuli

Our system detects early signs of stress and **responds with real-time environmental adjustments** and **breathing guidance**, helping both students and teachers.

## ⚙️ System Architecture

**Three-Module Collaborative Design**:
1. **Wristband Sensor** – collects HRV, GSR, motion data  
2. **Central Control System** – analyzes signals and determines state  
3. **Smart Glasses/App** – displays intervention prompts (e.g., reduce brightness, breathing guide)

Example:
> [Check] Heart Rate > 120 → [Action] Lower transmittance to 70% + Start guided breathing

## 🧠 Technical Highlights

- Multimodal signal fusion (HRV + GSR + motion)
- Scenario-specific adaptive feedback
- Ethical consideration: no autonomous AI diagnosis, only data-based prompts
- Data privacy prioritized for all biometric inputs


## 🖼️ Features in Progress

- Chat-based interface for classroom communication
- Entity-relationship model to track students, guardians, and support history
- UI/UX prototype to simulate real classroom use


## 🛡️ Ethical Focus

All AI actions are **explainable and data-grounded**, avoiding black-box analysis. Medical data is handled as sensitive and secured to the highest standard.


## 💡 Future Directions

- Real deployment in special education classrooms
- Integration with **wearable EEG** for finer stress detection
- Expansion to support **ADHD**, **anxiety**, and other neurodiverse profiles
